# Loop

**Un format de données pour l'information destinée à l'IA.**

`.loop` est un format de fichiers pensé pour représenter l'information de façon
structurée et lisible pour les modèles : pas un simple stockage de données, mais une
mise en forme qui préserve le sens.

## Format

- Version : v1.0
- Implémentation : Python 3.10+
